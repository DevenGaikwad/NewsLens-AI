# Third-Party Components

NewsLens AI depends on packages listed in `requirements-lite.txt` and `web/package-lock.json`. Each package retains its upstream copyright and license. Principal runtime families include Streamlit, pandas, NumPy, scikit-learn, Joblib, Plotly, Matplotlib, Seaborn, Requests, Beautiful Soup, Trafilatura, pypdf, ReportLab, and pytest.

The optional web reference source uses Next.js, React, TypeScript, and related tooling. Vercel is not required for Phase 5S.

Research papers and tutorials listed in the research matrix are cited as background and are not copied into or used to train the synthetic dataset. No external pretrained summarization checkpoint is packaged.

The synthetic dataset has its separate CC BY 4.0 notice. The remainder of the original project is governed by the repository's proprietary source-visible notice unless a dependency or file states otherwise.
